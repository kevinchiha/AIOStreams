# Kevbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Key-in-URL family config for the AIOStreams fork — one shared template config installed per allowlisted family member via `https://streams.kevbox.dev/stremio/k/{name}/{premiumizeApiKey}/manifest.json`, plus Torrentio at #1, Kevbox branding, auto-updates, and VPS deployment.

**Architecture:** A new stateless route `/stremio/k/:name/:apiKey` mirrors the stock authenticated Stremio router but builds `UserData` from a repo-versioned JSON template (`kevbox.config.json`, `${ENV_VAR}` placeholders for secrets) instead of a DB lookup. Members are gated by a `KEVBOX_MEMBERS` env allowlist; the operator config-access key is injected per request so `AIOSTREAMS_AUTH_REQUIRED=true` never breaks family URLs. Upstream edits: 3 lines in `app.ts`, 1 regex in `middlewares/errors.ts`, ~10 lines in `server.ts` (fail-loud boot check), 1 line in `core/src/db/schemas.ts`, 1 expression in `core/src/main/index.ts` — **5 upstream source files** (plus a 3-line `.gitignore` append). Everything else is new files.

**Tech Stack:** TypeScript (ESM, NodeNext — relative imports need `.js` extension), Express 5, Zod, vitest 2 (workspace root devDep, `*.test.ts` colocated), pnpm workspaces, Docker Compose.

```ts
import { existsSync, readFileSync, statSync } from 'node:fs';

const PLACEHOLDER_REGEX = /\$\{([A-Z][A-Z0-9_]*)\}/g;

/**
 * Replace ${ENV_VAR} placeholders with JSON-escaped env values.
 * Throws listing every missing/empty variable so a misconfigured
 * deployment fails with one complete, actionable message.
 */
export function substituteEnvPlaceholders(
  raw: string,
  env: NodeJS.ProcessEnv
): string {
  const missing = new Set<string>();
  const result = raw.replace(PLACEHOLDER_REGEX, (_match, name: string) => {
    const value = env[name];
    if (value === undefined || value === '') {
      missing.add(name);
      return '';
    }
    // JSON-escape so quotes/backslashes in secrets cannot corrupt the document
    return JSON.stringify(value).slice(1, -1);
  });
  if (missing.size > 0) {
    throw new Error(
      `kevbox template references unset environment variables: ${[...missing].join(', ')}`
    );
  }
  return result;
}

interface CacheEntry {
  mtimeMs: number;
  template: Record<string, unknown>;
}

const cache = new Map<string, CacheEntry>();

/**
 * Load, substitute and parse the kevbox template, cached by file mtime.
 * Env values are assumed static for the process lifetime (substitution
 * is part of the cached result).
 */
export function loadKevboxTemplate(
  filePath: string,
  env: NodeJS.ProcessEnv = process.env
): Record<string, unknown> {
  const { mtimeMs } = statSync(filePath);
  const cached = cache.get(filePath);
  if (cached && cached.mtimeMs === mtimeMs) {
    return cached.template;
  }
  const raw = readFileSync(filePath, 'utf-8');
  const substituted = substituteEnvPlaceholders(raw, env);
  let template: Record<string, unknown>;
  try {
    template = JSON.parse(substituted) as Record<string, unknown>;
  } catch (error: unknown) {
    throw new Error(
      `kevbox template at ${filePath} is not valid JSON: ${
        error instanceof Error ? error.message : String(error)
      }`
    );
  }
  cache.set(filePath, { mtimeMs, template });
  return template;
}

export type KevboxTemplateCheck = { ok: true } | { ok: false; reason: string };

/**
 * Boot-time structural check: file exists, placeholders resolve, JSON parses,
 * and the template has presets plus a premiumize service entry. Full schema
 * validation happens per-request via validateConfig.
 */
export function checkKevboxTemplate(
  filePath: string,
  env: NodeJS.ProcessEnv = process.env
): KevboxTemplateCheck {
  if (!existsSync(filePath)) {
    return { ok: false, reason: `template file not found at ${filePath}` };
  }
  try {
    const template = loadKevboxTemplate(filePath, env);
    const services = template.services;
    const hasPremiumize =
      Array.isArray(services) &&
      services.some(
        (service) =>
          typeof service === 'object' &&
          service !== null &&
          (service as { id?: unknown }).id === 'premiumize'
      );
    if (!hasPremiumize) {
      return { ok: false, reason: 'template has no premiumize service entry' };
    }
    if (!Array.isArray(template.presets) || template.presets.length === 0) {
      return { ok: false, reason: 'template has no presets' };
    }
    return { ok: true };
  } catch (error: unknown) {
    return {
      ok: false,
      reason: error instanceof Error ? error.message : String(error),
    };
  }
}
```

```ts
import { createHash } from 'node:crypto';
import type { UserData } from '@aiostreams/core';

export const KEVBOX_NAME_REGEX = /^[a-z0-9-]{1,20}$/;
export const KEVBOX_API_KEY_REGEX = /^[A-Za-z0-9_-]{8,128}$/;

/** Invalid member name / API key — maps to a user-facing error, not a 500. */
export class KevboxParamError extends Error {}

/**
 * Deterministic UUIDv5-format id derived from the member name, so a member's
 * identity is stable across Premiumize key rotations. Safe to share per name
 * because the KEVBOX_MEMBERS allowlist (middleware) is the only way in.
 */
export function syntheticUuid(name: string): string {
  const digest = createHash('sha1').update(`kevbox.dev:${name}`).digest();
  const bytes = Buffer.from(digest.subarray(0, 16));
  bytes[6] = (bytes[6] & 0x0f) | 0x50; // version 5
  bytes[8] = (bytes[8] & 0x3f) | 0x80; // RFC 4122 variant
  const hex = bytes.toString('hex');
  return [
    hex.slice(0, 8),
    hex.slice(8, 12),
    hex.slice(12, 16),
    hex.slice(16, 20),
    hex.slice(20, 32),
  ].join('-');
}

export function memberDisplayName(name: string): string {
  return name.charAt(0).toUpperCase() + name.slice(1);
}

/**
 * Build a per-member UserData from the kevbox template: validate URL params,
 * inject the Premiumize key, the operator config-access key (when the auth
 * gate is active) and member identity. Never mutates the (cached) template.
 */
export function buildKevboxUserData(
  template: Record<string, unknown>,
  name: string,
  apiKey: string,
  baseUrl: string,
  accessKey?: string | null
): UserData {
  if (!KEVBOX_NAME_REGEX.test(name)) {
    throw new KevboxParamError(
      `Invalid kevbox member name "${name}" — expected 1-20 chars of a-z, 0-9 or "-"`
    );
  }
  if (!KEVBOX_API_KEY_REGEX.test(apiKey)) {
    throw new KevboxParamError('Invalid Premiumize API key format');
  }

  const cloned = structuredClone(template) as UserData;
  const services = (cloned.services ?? []).map((service) =>
    service.id === 'premiumize'
      ? {
          ...service,
          enabled: true,
          credentials: { ...service.credentials, apiKey },
        }
      : service
  );
  if (!services.some((service) => service.id === 'premiumize')) {
    throw new KevboxParamError(
      'kevbox template has no premiumize service entry'
    );
  }

  return {
    ...cloned,
    services,
    uuid: syntheticUuid(name),
    addonName: `Kevbox (${memberDisplayName(name)})`,
    selfManifestUrl: `${baseUrl}/stremio/k/${name}/${apiKey}/manifest.json`,
    ...(accessKey ? { accessKey } : {}),
  };
}
```

Note: if `tsc` reports that `services` elements don't satisfy the core service type (credentials typing), adjust the map callback's typing to match the core type — the shape `{ id, enabled, credentials: Record<string, string> }` is what `UserDataSchema.services` defines; do not cast to `any`.

Create `packages/server/src/routes/stremio/kevbox.ts`:

```ts
import { NextFunction, Request, Response, Router } from 'express';
import path from 'node:path';
import {
  APIError,
  config as appConfig,
  constants,
  createLogger,
  getConfigAccessKey,
  Resource,
  StremioTransformer,
  validateConfig,
} from '@aiostreams/core';
import { corsMiddleware } from '../../middlewares/index.js';
import { loadKevboxTemplate } from '../../utils/kevboxTemplate.js';
import {
  buildKevboxUserData,
  KevboxParamError,
} from '../../utils/kevboxUserData.js';
import manifest from './manifest.js';
import stream from './stream.js';
import meta from './meta.js';
import catalog from './catalog.js';
import subtitle from './subtitle.js';
import addonCatalog from './addonCatalog.js';

const logger = createLogger('server');

// Mirrors VALID_RESOURCES in middlewares/userData.ts (minus configure,
// which the kevbox router handles with its own redirect below).
const VALID_RESOURCES = [
  ...constants.RESOURCES,
  'manifest.json',
  'manifest',
  'streams',
];

export function kevboxTemplatePath(): string {
  return (
    process.env.KEVBOX_TEMPLATE_PATH ??
    path.resolve(process.cwd(), 'kevbox.config.json')
  );
}

/** The member allowlist. Empty array = kevbox disabled on this instance. */
export function kevboxMembers(env: NodeJS.ProcessEnv = process.env): string[] {
  return (env.KEVBOX_MEMBERS ?? '')
    .split(',')
    .map((member) => member.trim())
    .filter((member) => member.length > 0);
}

interface KevboxParams {
  name?: string;
  apiKey?: string;
  [key: string]: string | string[] | undefined;
}

export const kevboxUserDataMiddleware = async (
  req: Request<KevboxParams>,
  res: Response,
  next: NextFunction
) => {
  const { name, apiKey } = req.params;

  const resourceRegex = new RegExp(`/(${VALID_RESOURCES.join('|')})`);
  const resourceMatch = req.path.match(resourceRegex);
  if (!resourceMatch) {
    next();
    return;
  }
  const resource = resourceMatch[1];

  // Same user-facing error pattern as middlewares/userData.ts: Stremio
  // resources get a playable "error stream" response, anything else an APIError.
  const respondWithError = (description: string) => {
    if (constants.RESOURCES.includes(resource as Resource)) {
      res.status(200).json(
        StremioTransformer.createDynamicError(resource as Resource, {
          errorDescription: description,
        })
      );
      return;
    }
    next(new APIError(constants.ErrorCode.USER_INVALID_DETAILS));
  };

  if (!name || !apiKey) {
    respondWithError('Missing kevbox member name or API key');
    return;
  }

  if (!kevboxMembers().includes(name)) {
    logger.warn(`kevbox: rejected unknown member name "${name}"`);
    respondWithError(
      `"${name}" is not an allowed kevbox member — ask Kevin to add you`
    );
    return;
  }

  // Template-load failures (missing file, unset env var, bad JSON) get a
  // friendly error stream, never an opaque 500 — these are exactly the
  // misconfigurations a family member would otherwise hit blind.
  let template: Record<string, unknown>;
  try {
    template = loadKevboxTemplate(kevboxTemplatePath());
  } catch (error: unknown) {
    const message = error instanceof Error ? error.message : String(error);
    logger.error(`kevbox: template failed to load: ${message}`);
    respondWithError('Kevbox is misconfigured on the server — tell Kevin');
    return;
  }

  try {
    let userData = buildKevboxUserData(
      template,
      name,
      apiKey,
      appConfig.bootstrap.baseUrl,
      getConfigAccessKey()
    );
    userData = { ...userData, ip: req.userIp };

    try {
      userData = await validateConfig(userData, {
        skipErrorsFromAddonsOrProxies: true,
        decryptValues: true,
      });
    } catch (error: unknown) {
      const message = error instanceof Error ? error.message : String(error);
      logger.error(`kevbox: invalid config for member ${name}: ${message}`);
      respondWithError(message);
      return;
    }

    req.userData = userData;
    req.uuid = userData.uuid;
    logger.debug(`kevbox: serving ${resource} for member ${name}`);
    next();
  } catch (error: unknown) {
    if (error instanceof KevboxParamError) {
      respondWithError(error.message);
      return;
    }
    const message = error instanceof Error ? error.message : String(error);
    logger.error(`kevbox: middleware failure for member ${name}: ${message}`);
    next(new APIError(constants.ErrorCode.INTERNAL_SERVER_ERROR));
  }
};

const kevboxRouter: Router = Router({ mergeParams: true });
kevboxRouter.use(corsMiddleware);
kevboxRouter.use(kevboxUserDataMiddleware);
kevboxRouter.use('/manifest.json', manifest);
kevboxRouter.use('/stream', stream);
kevboxRouter.use('/meta', meta);
kevboxRouter.use('/catalog', catalog);
kevboxRouter.use('/subtitles', subtitle);
kevboxRouter.use('/addon_catalog', addonCatalog);
// The shared manifest hardcodes behaviorHints.configurable: true; send
// Configure taps to the instance configure page (behind the operator login
// when AIOSTREAMS_AUTH_REQUIRED=true) instead of the :uuid router's 400.
kevboxRouter.get('/configure', (_req: Request, res: Response) => {
  res.redirect('/stremio/configure');
});

export default kevboxRouter;
```

- [ ] **Step 2: Create scripts/kevbox-update.sh**

```bash
#!/usr/bin/env bash
# Kevbox auto-update v2: sync from origin (the source of truth — this is what
# deploys template edits and manually resolved merges), merge the newest
# upstream release tag, rebuild, redeploy with a DB snapshot, health-check the
# kevbox route itself, roll back code AND data on failure, and alert on
# anything that needs Kevin. Idempotent; safe to run repeatedly.
#
# Run as the deploy user (NOT root): git >= 2.35.2 refuses to operate on a
# repo owned by another user ("dubious ownership"), which would kill every
# run under set -e. The user must be in the docker group.
set -euo pipefail

REPO_DIR="${KEVBOX_REPO_DIR:-/opt/kevbox/AIOStreams}"
COMPOSE_FILE="compose.kevbox.yaml"
BASE="${KEVBOX_BASE_URL:-http://127.0.0.1:3127}"
STATE_DIR="${KEVBOX_STATE_DIR:-/opt/kevbox/state}"
STATE_FILE="$STATE_DIR/deployed-sha"
FAILED_TAGS_FILE="$STATE_DIR/failed-tags"

log() { echo "[kevbox-update] $(date -Is) $*"; }
alert() {
  log "ALERT: $*"
  if [ -n "$NTFY_URL" ]; then
    curl -fsS -m 10 -d "kevbox-update: $*" "$NTFY_URL" >/dev/null 2>&1 ||
      log "ntfy delivery failed"
  fi
}

mkdir -p "$STATE_DIR"
exec 9>"$STATE_DIR/.lock"
flock -n 9 || { log "another run holds the lock; exiting"; exit 0; }

cd "$REPO_DIR"

# Webhook for alerts: env override, else the repo .env — the systemd unit
# does NOT source .env, so without this grep every timer-driven run would
# silently degrade to log-only alerting.
NTFY_URL="${KEVBOX_NTFY_URL:-$(grep -E '^KEVBOX_NTFY_URL=' .env 2>/dev/null | cut -d= -f2- || true)}"

probe_member() {
  # First allowlisted member from .env — used for the kevbox health probe.
  grep -E '^KEVBOX_MEMBERS=' .env | cut -d= -f2- | cut -d, -f1 | tr -d ' '
}

health_gate() {
  # /api/v1/health only checks the DB and stays green while kevbox is broken;
  # the manifest probe is what actually protects the kevbox routes. The body
  # is buffered (no curl|grep pipeline) so grep -q's early exit can't surface
  # as a SIGPIPE failure under pipefail and fail the gate on a HEALTHY deploy.
  local member body
  member="$(probe_member)"
  for _ in $(seq 1 12); do
    sleep 5
    body="$(curl -fsS "$BASE/stremio/k/${member}/healthprobe0000/manifest.json" 2>/dev/null || true)"
    if curl -fsS "$BASE/api/v1/health" >/dev/null 2>&1 &&
      grep -q '"Kevbox (' <<<"$body"; then
      return 0
    fi
  done
  return 1
}

# Snapshot/restore via a throwaway container so bind-mount file ownership
# never matters. Migrations are up-only and run at boot; a rolled-back build
# against a migrated DB exits at startup — rollback MUST restore the data dir.
snapshot_data() {
  docker run --rm -v "$REPO_DIR/data:/data:ro" -v "$STATE_DIR:/backup" alpine \
    tar -czf /backup/data-pre-deploy.tar.gz -C /data .
}

restore_data() {
  docker run --rm -v "$REPO_DIR/data:/data" -v "$STATE_DIR:/backup" alpine \
    sh -c 'find /data -mindepth 1 -delete && tar -xzf /backup/data-pre-deploy.tar.gz -C /data'
}

rollback() {
  local sha="$1"
  log "rolling back to $sha"
  docker compose -f "$COMPOSE_FILE" stop
  restore_data
  git reset --hard "$sha"
  docker compose -f "$COMPOSE_FILE" build
  docker compose -f "$COMPOSE_FILE" up -d
  if health_gate; then
    alert "update failed; rolled back to $sha and healthy again"
  else
    alert "CRITICAL: rollback to $sha is ALSO unhealthy — manual intervention required"
  fi
}

git fetch origin --tags --quiet
git fetch upstream --tags --quiet
git checkout kevbox --quiet

# Origin is the source of truth (template edits, resolved merges).
LOCAL="$(git rev-parse kevbox)"
REMOTE="$(git rev-parse origin/kevbox)"
MERGE_BASE="$(git merge-base kevbox origin/kevbox)"
if [ "$LOCAL" = "$REMOTE" ]; then
  : # in sync
elif [ "$LOCAL" = "$MERGE_BASE" ]; then
  log "fast-forwarding to origin/kevbox"
  git merge --ff-only origin/kevbox --quiet
elif [ "$REMOTE" = "$MERGE_BASE" ]; then
  log "local is ahead of origin (a previous push failed); will push after deploy"
else
  alert "kevbox has DIVERGED from origin — resolve manually on a workstation"
  exit 1
fi

# Newest stable upstream release tag (pre-release suffixes excluded
# defensively — git's version sort can rank v2.x.0-rc1 above v2.x.0).
# The trailing '|| true' guards two pipefail aborts that would kill the run
# before any alert(): grep matching nothing, and grep dying with SIGPIPE
# when head closes the pipe early.
LATEST_TAG="$(git tag --list 'v*' --sort=-version:refname |
  grep -Ev -- '-(rc|beta|alpha|pre)' | head -n1 || true)"
MERGED_TAG=""
if [ -n "$LATEST_TAG" ] && ! git merge-base --is-ancestor "$LATEST_TAG" kevbox; then
  if [ -f "$FAILED_TAGS_FILE" ] && grep -qxF "$LATEST_TAG" "$FAILED_TAGS_FILE"; then
    log "skipping $LATEST_TAG — previously failed (clear $FAILED_TAGS_FILE to retry)"
  else
    log "merging $LATEST_TAG"
    if ! git merge --no-edit "$LATEST_TAG"; then
      git merge --abort
      alert "merge conflict with $LATEST_TAG — manual resolution required"
      exit 1
    fi
    MERGED_TAG="$LATEST_TAG"
  fi
fi

DEPLOYED_SHA="$(cat "$STATE_FILE" 2>/dev/null || echo '')"
HEAD_SHA="$(git rev-parse HEAD)"
if [ "$HEAD_SHA" = "$DEPLOYED_SHA" ]; then
  log "already deployed $HEAD_SHA; nothing to do"
  exit 0
fi

log "building $HEAD_SHA"
if ! docker compose -f "$COMPOSE_FILE" build; then
  alert "build failed at $HEAD_SHA — running deployment untouched"
  if [ -n "$MERGED_TAG" ]; then echo "$MERGED_TAG" >>"$FAILED_TAGS_FILE"; fi
  if [ -n "$DEPLOYED_SHA" ]; then git reset --hard "$DEPLOYED_SHA"; fi
  exit 1
fi

log "deploying $HEAD_SHA (snapshotting data dir first)"
docker compose -f "$COMPOSE_FILE" stop
snapshot_data
docker compose -f "$COMPOSE_FILE" up -d

if health_gate; then
  echo "$HEAD_SHA" >"$STATE_FILE"
  if ! git push origin kevbox --quiet; then
    # A silent push failure would let VPS and origin diverge until every
    # later run errors — this must be loud.
    alert "deployed $HEAD_SHA but push to origin FAILED — origin and VPS are out of sync"
    exit 1
  fi
  docker image prune -f >/dev/null 2>&1 || true
  log "deployed $HEAD_SHA successfully"
  exit 0
fi

alert "UNHEALTHY after deploying $HEAD_SHA"
if [ -n "$MERGED_TAG" ]; then echo "$MERGED_TAG" >>"$FAILED_TAGS_FILE"; fi
if [ -n "$DEPLOYED_SHA" ]; then
  # '|| true' keeps set -e from killing the script mid-rollback before the
  # function's own alerts (including the CRITICAL one) can fire.
  rollback "$DEPLOYED_SHA" || true
else
  alert "CRITICAL: first deploy unhealthy and no previous version recorded — manual intervention required"
fi
exit 1
```

Note: a broken commit pushed to origin (not a tag) is retried daily by design — it's Kevin's own commit and the fix is another push. Only failed *tags* are blocklisted.

One URL per member — same shared config, their own Premiumize key:

  name) is cached by Stremio clients and may effectively need a reinstall.

## The template

`kevbox.config.json` at the repo root is the single shared config. Secrets are
`${ENV_VAR}` placeholders substituted at load time — never commit real values.

| Env var | Purpose |
| --- | --- |
| `KEVBOX_MEMBERS` | Member allowlist (comma-separated). Required — kevbox is off without it |
| `KEVBOX_TEMPLATE_PATH` | Optional override of the template location (default `<cwd>/kevbox.config.json`; the compose file bind-mounts it to `/app/kevbox.config.json`) |
| `KEVBOX_MEDIAFLOW_URL` | MediaFlow proxy URL |
| `KEVBOX_MEDIAFLOW_PASSWORD` | MediaFlow API password |
| `KEVBOX_RPDB_KEY` | RPDB poster service key |
| `KEVBOX_NTFY_URL` | Optional webhook for auto-update alerts (conflicts, rollbacks, push failures). The update script reads it from this `.env` — the systemd unit does not source it |
| `KEVBOX_REPO_DIR` / `KEVBOX_BASE_URL` / `KEVBOX_STATE_DIR` | Auto-update script overrides (repo dir, base URL for both health-gate probes, state dir) |

Not running MediaFlow? Delete the `proxy` block from the template. No RPDB
key? Set `"posterService": "none"` and remove `rpdbApiKey`.

With `KEVBOX_MEMBERS` set, a broken template **fails server boot** (and the
auto-update rolls back) instead of failing at a family member's request.

Deploy: `docker compose -f compose.kevbox.yaml up -d --build` from the repo
checkout on the VPS (binds 127.0.0.1:3127, fronted by the reverse proxy —
